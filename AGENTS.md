# AGENTS.md

## Project Overview

This project is a modern Scratch-based coding platform.

## Development

- Use Node.js 20.

- Use npm for package management.

- Keep source code organized inside the project packages and source directories.

- Follow the project's existing coding conventions.

- Run linting and tests before committing changes.

## Code Changes

When modifying the project:

1. Understand the existing architecture before changing files.

2. Keep changes focused on the requested feature.

3. Avoid unnecessary dependencies.

4. Preserve existing Scratch functionality.

5. Add tests for new functionality when appropriate.

## Git

Use clear commit messages that describe the change.

Before committing:

- Check the changed files.

- Run relevant tests.

- Run linting.

- Make sure generated files are not accidentally committed.

## Scratch Mod Development

New blocks, extensions, UI features, and editor functionality should integrate with the existing Scratch architecture rather than replacing core systems unnecessarily.

Keep the project compatible with modern Scratch-style projects and extensions.
